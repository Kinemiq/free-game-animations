# Free Game Animations (CC0) – FBX + GLB

35 humanoid game animations under **CC0** – free for commercial games, no credit needed.
Idles, walks, runs, sprint, crouch, jump (take-off, air, landing), roll, punches (jab, cross, hook), hit reactions,
a death, get up, sit down / stand up, a dance, climb, pick up, sword slash / idle / block – on one humanoid skeleton
(66 bones, 30 fps), plus a mannequin character.

## Download
See **Releases**:
- `KinemIQ_Free_Animations_CC0_FBX.zip` – FBX (Unity Humanoid, Unreal Engine, Blender)
- `KinemIQ_Free_Animations_CC0_GLB.zip` – GLB / glTF (Godot, three.js, Blender)

**Unity:** import `KinemIQ_Mannequin.fbx` and the clips, Rig = Humanoid (clips: Copy From Other Avatar).

**Unreal Engine, Godot, Blender:** import the FBX or GLB directly.
